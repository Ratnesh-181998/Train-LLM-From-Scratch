# Train Your Own LLM From Scratch Using PyTorch

- How to build and train a Transformer-based Large Language Model (LLM) from scratch using PyTorch.

## The repository covers the complete pipeline:

- Data collection and preprocessing using The Pile dataset
- Tokenization with tiktoken
- Single-Head and Multi-Head Self-Attention
- Transformer Blocks and Layer Normalization
- Training and evaluation workflows
-  Text generation and inference
-   caling from a 13M parameter model to billion-parameter architectures
